# Rahul Vashistha: portfolio

**Live site: [rahulvashistha.github.io](https://rahulvashistha.github.io)**

A portfolio built like a Power BI report. Pages: Professional (with drill-through case studies and Story mode), Personal, Hall of Fame and Yearbook. An Album page appears automatically once photos are added.

Plain HTML, CSS and JavaScript. No build step, no framework. Hosted free on GitHub Pages.

## Where things live

| Path | What it is |
|---|---|
| `data/` | All content: profile, projects, recreated reports, certificates and milestones, yearbook, personal page |
| `assets/` | Certificate images, project screenshots, photos, résumé PDF |
| `css/site.css` | Styles and the four themes |
| `js/` | Rendering code |

## Making changes

Read **[MAINTAINING.md](MAINTAINING.md)** first. It covers the file map, every data field, the content rules, step-by-step guides for common updates, a pre-publish checklist, and a ready-to-paste prompt for handing changes to an AI assistant.

Quick preview: double-click `index.html`. If a data file has a typo, the site shows a red banner naming the file.

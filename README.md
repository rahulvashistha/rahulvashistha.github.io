# Rahul Vashistha — portfolio

A two-page portfolio built like a Power BI report: **Professional** and **Personal**, switched with the page tabs at the bottom.

- Plain HTML, CSS and JavaScript in one file (`index.html`). No build step, no dependencies.
- Hosted free on GitHub Pages.
- Every value inside the recreated report visuals is sample data.

## Editing content

All text lives in the `DATA` object near the top of the `<script>` in `index.html`. The recreated reports live in `MOCKS` just below it.
